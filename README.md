
# 🍳 Piu Piu Recipes Website

Piu Piu Recipes Website is a simple, attractive, and user-friendly recipe website created using HTML, CSS, and JavaScript. The website allows users to explore different recipes and view useful information such as ingredients, cooking steps, cooking time, and nutrition information.

This project was developed as a front-end web development project to practice website structure, styling, navigation, and responsive design.
A modern and user-friendly restaurant website built with **HTML, CSS, and JavaScript**.  


## 🌐 Project Overview


Piu Piu Recipes Website provides a clean and simple interface for users who want to explore different food recipes.

The website focuses on:

- Recipe browsing
- Ingredients information
-  Cooking instructions
- Cooking time
-  Attractive and clean design
- Responsive layout
- Simple website navigation

## Run Locally 
Follow these steps to run the project on your computer.

### 1. Clone the Repository


git clone https://github.com/YOUR-USERNAME/Khana-Pina-Restaurant.git

 ### 2. Open the project

Open the project folder in Visual Studio Code.

### 3. Run the Website

Open index.html in your browser.

### For a better development experience : 
You can use the Live Server extension in VS Code:

- Open index.html
- Right-click inside the file
- Select Open with Live Server
- The website will open in your browser.
